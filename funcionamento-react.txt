começando entender react

useState


O que é useState?
É um Hook do React que:

Guarda um valor entre renderizações

Quando esse valor muda → React re-renderiza o componente e atualiza a UI

Exemplo:

javascript
const [count, setCount] = useState(0)
useState(0) inicializa o state com o valor 0

count é o valor atual do state

setCount é a função que atualiza o state

Quando chamamos setCount(count + 1):

O React atualiza o valor de count para 1

Re-executa o componente

Compara as mudanças

Atualiza a interface do usuário (UI) com o novo valor


React não atualiza a tela.
Ele re-executa o componente e recalcula a UI.(user interface)
